## 服务器证据

服务器证据必须由课程分配的 Ubuntu 主机真实运行后填写，不能用 Windows 静态检查或 E3 的 WSL 日志替代。正式交付应选择两份独立克隆的成功运行目录，记录：

- 服务器环境与 Docker 版本；
- 被测源码完整 SHA；
- 两名操作者或两份独立学号目录；
- `env.json`、`build.log`、`image.json`、`toolchain.lock`；
- `test.log`、`smoke.json`、`secret-scan.txt`；
- 假 Key 检出与清理后复扫记录；
- 两次结果的对照与合理差异。

镜像 ID、时间、进程号和 `trace_lines` 可能不同；源码 SHA、工具链版本、测试结论与冒烟结论应一致。
